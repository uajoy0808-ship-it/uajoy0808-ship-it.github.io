SNS Comment Assistant
ツールについてプライバシー利用について

投稿後の問いかけコメントを、
決めた内容で。

SNS Comment Assistant は、運用者本人のYouTube動画に、あらかじめ決めた問いかけコメントを投稿するための個人用ツールです。一般の利用者へのサービス提供・アカウント登録・販売は行っていません。

行うこと

  • 認証したチャンネルが、運用者本人のチャンネルであることを確認します。
  • 指定動画が本人の動画で、公開済みであることを確認します。
  • 同じコメントが既に存在しないか確認してから、予約した内容を投稿します。
  • 送信結果が不明な場合は、自動で再送せず停止します。

データの取り扱い

Googleの公式認証とYouTube Data APIを利用し、GitHub Actionsで実行します。詳しくはプライバシー方針および利用についてをご確認ください。

運用者

ひかる先生とひとみちゃんのYouTubeチャンネルの個人用ツールです。お問い合わせは同チャンネルに掲載する連絡方法をご利用ください。
