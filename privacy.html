SNS Comment Assistant
ツールについてプライバシー利用について

プライバシー方針

この方針は、運用者本人が利用するSNS Comment AssistantによるGoogle・YouTubeデータの取り扱いを説明します。

アクセスする情報と目的

Googleの公式認証で得た認証情報を用い、本人チャンネルの識別情報、指定動画の所有者と公開状態、重複確認に必要なコメントを取得します。目的は本人動画への予約コメントの投稿と、誤投稿・二重投稿の防止です。

求める権限と実装する操作

Googleの認証画面には、YouTubeの動画・評価・コメント・字幕の表示、編集、削除を含む権限が表示されます。コメント挿入APIに必要な権限であり、プログラムに実装している操作はチャンネルと動画の確認、コメントの読み取り、本人動画へのコメント挿入です。動画・評価・字幕の編集や削除の処理は実装していません。

保存と保護

認証情報は専用の非公開GitHubリポジトリのActions Secretsに保存します。初回認証時には運用者のMac内にもアクセスを制限したファイルとして保存します。GitHubでの実行時は一時ファイルに復元し、終了時に削除します。認証情報を公開ソースや実行成果物に含めません。

予約した投稿先・コメント・予定時刻と、二重投稿防止のための識別値・実行状態を非公開で保存します。視聴者のコメント本文は重複確認のために一時的に読み取り、実行ログや台帳には保存しません。実行ログ・レポートは原則7日で失効する設定です。

共有と利用範囲

認証・データ取得にはGoogle、認証情報の保管と自動実行にはGitHubを利用します。Googleから取得したデータを広告、販売、AIモデルの学習には利用しません。処理に必要な範囲を超えて第三者へ提供しません。

SNS Comment AssistantによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data PolicyのLimited Use要件に従います。

停止・削除

Googleアカウントのサードパーティとの接続から、本ツールへのアクセスを取り消せます。運用者はGitHub側の実行を停止し、Secrets、Mac内の認証ファイル、不要な予約データ・台帳を削除できます。アクセスの取り消しは、既に投稿されたコメントを削除する操作ではありません。必要なコメント削除は運用者がYouTube上で行います。

運用者と連絡先

運用者のYouTubeチャンネルに掲載する連絡方法をご利用ください。

方針の更新

利用目的や保存方法を変更する場合は、このページを更新し、必要に応じて改めて権限を確認します。
